# DotaBot

Собранный запуск: `C:\DotaBot\run_bot.bat`.

## Что уже сделано

- нативный Windows-интерфейс в тёмной теме с предпросмотром экрана;
- корректные абсолютные пути при запуске из `build`;
- встроенный GSI-сервер с безопасной остановкой;
- запись кадров, действий и GSI в одну демонстрационную сессию;
- обучение на всех папках `demos/demo_*`;
- временное выравнивание GSI по timestamp, а не по номеру строки;
- экспорт согласованной ONNX-модели (`models/model.onnx`);
- автоматическое подключение модели после завершения обучения;
- детерминированный fallback вместо случайных кликов;
- команда `run_bot.bat` пытается установить GSI-конфигурацию в Steam.

## Запуск

1. Запусти `run_bot.bat`.
2. В окне DotaBot нажми **Записать демо** и сыграй тренировочную игру.
3. Нажми **Остановить запись**.
4. Нажми **Обучить модель**.
5. После сообщения `Training completed and model reloaded` можно запускать бота.

Проверка установки:

```powershell
C:\DotaBot\venv\Scripts\python.exe C:\DotaBot\validator.py
```

## Важное ограничение про файлы `.dem`

Файл replay `.dem` не содержит обычные скриншоты рабочего стола и нажатия
клавиш игрока. Поэтому модель обучается на сессиях формата `demos/demo_*`
(кадры + actions.jsonl + необязательный gsi.jsonl). Сам бинарный `.dem` нельзя
честно превратить в такие screen-action пары простым переименованием. Для
обучения по реплеям других игроков используй запись экрана реплея в режиме
наблюдателя и добавляй метки действий, либо подготовь импортёр под конкретный
парсер Source 2 demo.

Бот не должен использоваться в рейтинговой игре или для обхода правил Steam/Dota 2.
